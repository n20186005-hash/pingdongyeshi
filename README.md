# Pingtung Night Market guide

Independent, unofficial, nonprofit educational visitor information. Existing pages: Traditional Chinese home, food, transport, hours, and English home. Static Astro with a small Cloudflare Worker for canonical entrances and real errors. No weather widget or analytics preference control.

Use the exact Node and pnpm versions declared in package.json. Normal commands: `pnpm install --frozen-lockfile`, `pnpm check`, `pnpm build`, `pnpm exec wrangler deploy --dry-run`. Existing native-script policy and dependency versions are retained. Worker project: `pingdongyeshi`.

Three original conceptual illustrations replace unverified photographs. They are not actual views, vendors or dishes. See the served `/CREDITS.txt`. Visitor information cites the county tourism page and a dated Maps snapshot, keeping vendor hours separate.
